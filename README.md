# Containerize a Static Website using Docker

## 📌 Project Overview

This project demonstrates how to containerize a static website using Docker.

The website is built using **HTML, CSS, and JavaScript** and is served using the **Nginx web server** inside a Docker container.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Docker
- Nginx
